# rm-ng-range-slider Code Examples

Welcome to the examples directory! Here you will find functional, copy-paste ready Angular components demonstrating various features and best practices for the `rm-ng-range-slider` library.

## Available Examples

### 1. [Basic Usage](./basic-usage)
The simplest way to get started. A clean implementation of a price range filter in a standalone component.
- **Key Features**: Inputs, Outputs, Standalone integration.

### 2. [Advanced Configuration](./advanced-configuration)
Explore the full visual power of the slider.
- **Key Features**: Dynamic theming, custom tooltip colors, color pickers, and live customization.

### 3. [Error Handling](./error-handling)
Learn how to build a robust UI that handles edge cases gracefully.
- **Key Features**: Boundary validation, visual error feedback (shake animation), and state protection.

### 4. [Performance Optimization](./performance-optimization)
Essential for large-scale applications.
- **Key Features**: `ChangeDetectionStrategy.OnPush`, RxJS `debounceTime`, and efficient event handling.

### 5. [UX Best Practices](./ux-best-practices)
Make your sliders accessible and pleasant for everyone.
- **Key Features**: ARIA labels, touch-friendly design, high-contrast themes, and real-time visual summaries.

### 6. [Conditional Rendering](./conditional-rendering)
Integration with dynamic layouts and lifecycles.
- **Key Features**: `@if` / `*ngIf` logic, state persistence between visibility toggles, and exit/entry animations.

---

## How to use these examples

1.  **Browse**: Click on any of the links above to view the code and a detailed explanation in the dedicated `README.md`.
2.  **Copy**: Each directory contains a `.ts` file that you can copy directly into your Angular project.
3.  **Adapt**: Modify the colors, bounds, and logic to fit your specific use case.

## Prerequisites
Most examples use modern Angular features:
- Angular 18+
- Standalone Components
- TypeScript 5.0+
