## Why This Library?

`rm-ng-range-slider` was created to provide a **robust, flexible, and modern range slider component** for Angular applications. Unlike many existing slider libraries, it focuses on **performance, customization, and developer experience** while remaining lightweight and dependency-free.

Key reasons to choose this library:

1. **Dual Thumb Support**
   Allows selection of a range of values on a single track with two independent thumbs, ideal for price ranges, filters, or multi-value inputs.

2. **Real-Time Tooltips**
   Dynamically displays selected values, giving immediate feedback to users and enhancing usability.

3. **Full Customization**
   Colors, thumb styles, track styles, and tooltips are fully customizable to match any design system or theme.

4. **Angular & TypeScript Ready**
   Written in TypeScript and fully compatible with Angular 18–21, supporting modern Angular features and type safety.

5. **Zero Dependencies**
   No external libraries are required, ensuring smaller bundle sizes and faster load times.

6. **Accessibility Focused**
   Designed with ARIA labels and keyboard navigation (planned) to support inclusive applications.

7. **Flexible & Extensible**
   Supports future enhancements like vertical orientation, multiple ranges, programmatic value setting, and integration with other UI components.

8. **Optimized for Performance**
   Lightweight code and minimal DOM manipulations ensure smooth interaction even on complex pages.

---

**In short:**
This library is ideal for developers seeking a **highly customizable, lightweight, and modern Angular range slider** with **dual-thumb support** and a **focus on usability and performance**.
